# Talia Desktop

Talia Desktop is [Liana](https://github.com/wizardsardine/liana) by Wizardsardine with the
Talia name and logo. Nothing else is changed: same features, same signing devices, same wallet
files and folder, same engine (`lianad`). Liana is BSD 3-Clause licensed; its copyright notice
is kept in `LICENCE`, next to ours.

## What this branch changes

| `liana-ui/src/font.rs`, `liana-ui/static/fonts/` | Talia iPhone app type: Figtree for text, Bricolage Grotesque for headings and bold (SIL OFL, licences beside the fonts) |
| `LICENCE` | Our copyright line under Wizardsardine's |

Kept on purpose: "Liana Connect" (Wizardsardine's own online service), "Liana descriptor"
(the file format), the "Liana daemon" (the engine), the `Liana-<checksum>` wallet ids, and the
data folder (`~/Library/Application Support/Liana`, `%APPDATA%\Liana`, `~/.liana`), so a client
who already uses Liana sees their wallets straight away.

The logo files are generated by `make_assets.py` from the Talia app icon and the brand font
(Bricolage Grotesque); the UI strings by `rebrand_i18n.py` (both in `contrib/talia/tools/`).

## Taking a new Liana release

1. `git fetch upstream --tags` and merge the new tag (for example `v17.0`) into this branch.
2. Re-run the text step on the new catalogs: `python3 -I contrib/talia/tools/rebrand_i18n.py liana-i18n/i18n`
   (it refuses to finish if one of the listed sentences moved, so nothing is missed silently).
3. `grep -n '"Liana' liana-gui/src -r` for any new sentence naming the app.
4. Build, open, check the start screen, a wallet, Settings > About.
5. Sign, notarise, publish.

## Building on a Mac

```
contrib/talia/build-macos-app.sh <output dir>             # this Mac's chip
UNIVERSAL=1 contrib/talia/build-macos-app.sh <output dir> # Apple silicon + Intel
```
